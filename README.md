# imnoob123 — inequalities

This version keeps the text short and puts the actual math first.

Includes:
- inequality notes
- theorem list
- hard problems with no solutions shown
- moving rainbow UI

The last two featured problems are from the official IMO shortlist:
- IMO 2006 Shortlist A5
- IMO 2023 Shortlist A4

For GitHub Pages, put `index.html`, `style.css`, and `script.js` in the root of `imnoob123-cpu.github.io`, then deploy from `main` / root.
