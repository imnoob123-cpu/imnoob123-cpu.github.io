# imnoob123 inequality site

This is the more casual / student-y version of the site.

The wording is intentionally less polished:
- short notes
- silly comments
- little rants
- "i have no idea why this worked" energy

## Files

- `index.html` — page content
- `style.css` — design and animations
- `script.js` — tiny interactions

## GitHub Pages

Put all three files in the root of your `imnoob123-cpu.github.io` repository.
Then enable Pages from the `main` branch and `/ (root)`.

Your site will be:

https://imnoob123-cpu.github.io/
