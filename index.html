01AM-GM

try the obvious thing first

If a positive-variable inequality has x/y and y/x sitting next to each other, don't invent a new branch of mathematics.

x/y + y/x ≥ 2

AM-GM. done.

02Cauchy

Engel form is actually useful

The one with Σx²/y. I keep forgetting to check for it, so here it is, on the website, where I can't pretend I forgot.

Σ(xᵢ² / yᵢ) ≥ (x₁ + ⋯ + xₙ)² / (y₁ + ⋯ + yₙ)
03SOS

subtract first

A lot of the time the inequality is easier to see after moving everything to one side.

(a-b)² + (b-c)² + (c-a)² ≥ 0

Cauchy-Schwarz

(\sum aᵢ²)(\sum bᵢ²) ≥ (\sum aᵢbᵢ)²

Useful when the expression looks like it wants a square.

AM-GM

(x₁+⋯+xₙ)/n ≥ ⁿ√(x₁⋯xₙ)

For positive xᵢ.

Schur

∑a(a-b)(a-c) ≥ 0

For a,b,c ≥ 0.

Jensen

f(∑λᵢxᵢ) ≤ ∑λᵢf(xᵢ)

For convex f and λᵢ ≥ 0, ∑λᵢ = 1.

Nesbitt

Σ a/(b+c) ≥ 3/2

For positive a,b,c.

uvw

u = a+b+c, v = ab+bc+ca, w = abc

Not a theorem by itself. Just a useful way to stop drowning in variables.

02 · harder

For positive a,b,c with a+b+c=1, prove

1/(1+a²) + 1/(1+b²) + 1/(1+c²) ≥ 9/4

Don't rush.

03 · actually mean

For x,y,z > 0, prove

(x+y+z)² ≥ 3(xy+yz+zx)

Find the cleanest proof you can.

04 · shortlist

Let a,b,c be the sides of a triangle. Prove

√(b+c-a)/√a + √(c+a-b)/√b + √(a+b-c)/√c ≤ 3

This one is from the 2006 IMO shortlist.

05 · functional

Find all f:(0,∞)→(0,∞) satisfying

x(f(x)+f(y)) ≥ (f(f(x))+y)f(y)

There is a clean answer. Good luck.
