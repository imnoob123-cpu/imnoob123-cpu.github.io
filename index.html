01 AM-GM

check AM-GM before doing something stupid

This happens way too often. I'll start expanding everything and then realize the inequality was one line with AM-GM.

x + y ≥ 2√xy

basically: try the easy stuff first.

02 substitution

sometimes the variables are the problem

If the expression looks horrible, rename it. A decent substitution can turn the whole thing into something familiar.

x = a/b,   y = b/c,   z = c/a

not always useful. very useful when it is.

03 SOS

if the gap looks like squares, you're probably done

A lot of inequalities become much nicer after subtracting the RHS and looking at what is left.

(a-b)² + (b-c)² + (c-a)² ≥ 0

i like these proofs because they're hard to mess up.

problems

try these

01

For positive x, y, prove

x/y + y/x ≥ 2
hint

AM-GM. this is basically free.

02

For positive a, b, c, prove

a/(b+c) + b/(c+a) + c/(a+b) ≥ 3/2
hint

try Cauchy in Engel form.

03

Prove

a² + b² + c² ≥ ab + bc + ca
hint

subtract the RHS and factor.
